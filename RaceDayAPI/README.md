# RaceDay Event Management API

## Overview

The RaceDay API is an ASP.NET Core .NET 8 application designed to support the RaceDay Event Management System. It works with information about users, organisers, participants, events, categories, enrolments, and race results.

## Technologies

- C#
- ASP.NET Core Web API
- .NET 8
- SQL Server
- Entity Framework Core

## Running the Project

Open the project in Visual Studio, confirm the database connection settings, restore the required packages, and run the API.
