# RaceDay Project Structure

The repository is organised to keep the Part 1 planning documents and GitHub workflow clearly separated.

## Documentation Folder

The `docs` folder contains the main Part 1 deliverables:

- `RaceDay_ERD_sketch.pdf` – Entity Relationship Diagram.
- `RaceDay_API_Endpoint_Plan.docx` – REST API endpoint planning document.
- `RaceDay.sql` – SQL Server database script.
- Supporting Part 1 documentation and design notes.

## GitHub Actions

The `.github/workflows` folder contains the GitHub Actions workflow used to validate the required Part 1 files.

## README

The `README.md` file provides an overview of the RaceDay Event Management System, its roles, Part 1 documentation,
database design, API planning, and CI/CD setup.
