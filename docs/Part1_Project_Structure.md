## Part 1 Deliverables

### ERD
The ERD defines the database entities, attributes, primary keys, foreign keys, and relationships required by the RaceDay Event Management System.

### API Endpoint Plan
The API Endpoint Plan identifies the RESTful endpoints required for authentication, user profiles, events, categories, enrolments, and results.

### SQL Database Script
The SQL script creates the RaceDay database structure, including tables, primary keys, foreign keys, constraints, and sample data.

### GitHub and CI/CD
GitHub Actions is configured to validate the required Part 1 files and repository structure automatically whenever changes are pushed to the repository.
